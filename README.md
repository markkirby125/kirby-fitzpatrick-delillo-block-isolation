## Core Patterns

- **Delillo Block Isolation**: DeLillo Block Isolation: isolate the target function into a clean scratchpad buffer away from file noise before refactoring.
- **Practical Application**: Refactoring dense legacy functions without surrounding file noise.
- **Verification Gate**: Enforces clean syntax, zero filler, and deterministic causality.
